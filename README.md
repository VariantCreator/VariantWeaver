# Variant Weaver

Create quests and events in Valheim with WeaverEditor, custom NPCs, dialogue, boss spawners and reward chests. Includes admin tools, travel points and kits.

**Beta, provided as-is, with frequent updates to come.**

[Download 1.1.3](https://github.com/VariantCreator/VariantWeaver/releases/download/v1.1.3/VariantMods-VariantWeaver-1.1.3.zip) · [Quick guide](GUIDE.md) · [Changelog](CHANGELOG.md)

## Install

Install BepInExPack Valheim, then import the ZIP into your mod manager. For manual installs, copy `plugins/VariantWeaver` into `BepInEx/plugins`.

Install the same version on the server or host and every player's client. Keep both DLLs together.

## Play

Press **F8** in a world. Admins get the editor; players get **Travel & Kits**. **/kit** and **/travel** open those tabs directly. Editing requires admin or role permission.

Weaver finds items and creatures from installed mods. Everyone needs any content mods your quests use.
